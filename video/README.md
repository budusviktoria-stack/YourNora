# Видео «your nora»

Генератор роликов в стиле референса: Нора, комната, переписки и дневник рисуются в SVG, кадры снимаются Playwright, видео собирает ffmpeg.

## Как собрать эпизод

```bash
cd video
node render.mjs ep02 --audio audio/ep02-voice.wav
```

Результат: `out/ep02.mp4` (с субтитрами) и `out/ep02-clean.mp4` (без субтитров), 1080×1920, 30 fps.

Проверить отдельные кадры, не собирая всё видео: `node render.mjs ep02 --stills 5,20,40`.

## Как сделать новый эпизод

1. Напишите сценарий в `scripts/`.
2. Запишите озвучку и положите её в `audio/epXX-voice.wav`.
3. Скопируйте `episodes/ep02.js` в `episodes/epXX.js`, поменяйте сцены и тайминги.
   В `CAPTIONS` у каждого слова указано время начала в озвучке, по нему подсвечиваются субтитры.

## Файлы

- `engine.js`: Нора, комната, улица, кафе, зайчик, переписка, снег, субтитры, заставка.
- `episodes/`: сцены и тайминги каждого эпизода.
- `render.mjs`: рендер в mp4.
- `fonts/`: Nunito и Caveat (лицензия SIL OFL).
