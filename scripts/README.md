# Сценарии «your nora»

Формат взят с референса (эпизод 01): вертикальное видео 9:16, около 60 секунд, 9–11 сцен.
Субтитры появляются по словам, мысли Норы выводятся рукописным шрифтом сверху,
в финале фраза из дневника и заставка канала.

## Структура каждого ролика

| Блок | Время | Что происходит |
|---|---|---|
| Хук | 0–3 с | Вопрос или резкая фраза + Нора в кадре |
| Ситуация | 3–15 с | Конкретный момент из её жизни (телефон, переписка, действие) |
| Мысль | 15–22 с | Крупный план, внутренний голос рукописным текстом |
| Причина | 22–35 с | Психологический механизм (часто флешбэк в сепии) |
| Поворот | 35–45 с | Окно / снег, «но…» — новый взгляд |
| Развязка | 45–53 с | Маленькое действие или событие, тёплый момент |
| Дневник | 53–59 с | «Из дневника Норы: …» |
| Заставка | 59–62 с | your nora / her little world / подпишись, чтобы узнать, что будет дальше |

## Обозначения в таблицах

- **Кадр** — что рисуем и как двигается камера.
- **На экране** — тексты поверх кадра (переписки, мысли, счётчики).
- **Озвучка** — то, что читает голос; эти же слова идут субтитрами.

## Правила (из концепции)

- Нора выглядит одинаково: длинные тёмно-каштановые волосы, серо-голубые глаза, большой свитер, наушники.
- Постоянные детали: окно со снегом и луной, лампа, фото на стене, дневник, зайчик.
- Чередовать: психология → личная история → её маленький мир.
- Не повторять одинаковую последовательность кадров подряд.
- События продолжаются — сверяться с `canon.md`.
